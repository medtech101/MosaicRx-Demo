Personal Study Agent

A private companion that de-identifies your lecture files, maps them into a bibliometric knowledge graph, attaches learning resources, and builds a spaced-repetition study schedule — all for one person, on your own instance.

De-identification pipeline Knowledge graph Resource enrichment Spaced-repetition scheduler Export center

Launch a live instance (one click)

This is a real full-stack app (a Python server with a database), so it can't run on GitHub Pages — this page is just the front door. The button below deploys the whole app to a free Render web service and gives you a live URL that works on your phone.


→ Deploy to Render

In the Render flow, pick the branch that contains study-agent/ (or merge it to main first). Every secret it asks for is optional. Free tier sleeps when idle and resets its database on restart — attach a paid disk at /app/backend/data for durable storage.

Or run it yourself (one command)

Local / any machine — then open it on your phone via the machine's LAN IP: 
cd study-agent
./run.sh
Docker — deploys to any container host: 
cd study-agent
docker build -t study-agent .
docker run -p 8000:8000 study-agent

Both serve the UI and API together on http://localhost:8000.

How it stays private

  • Mandatory sanitization before anything is stored: blocklist + name/org detection, metadata scrubbing, and logo/watermark removal, with a review screen you approve first.
  • Original uploads are deleted the moment you confirm — only sanitized versions persist.
  • No share, publish, or public-link feature exists anywhere — and every export is re-scanned against your blocklist right before download.
